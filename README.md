把拼音、形码和选字分成两个清楚的阶段：**空格前安心编码，空格后再选候选。**
基于恢复的字码、词库与基础排序实现，配合独立用户词库，支持日常使用中的逐字组合与新词学习。

## 快速安装

需要已安装 **Rime 前端 + librime-lua**；自动安装还需要 **Python 3.8+**。
项目由 Lua 引擎和数据组成，使用时无需编译 C++。

### 1. 获取项目

```sh
git clone https://github.com/andelf/remi-znabc.git
cd remi-znabc
```

也可以下载仓库 ZIP 并解压。基础词库已随仓库提供，无需另找原始程序或重新提取数据。

### 2. 安装到 Rime 用户目录

macOS 鼠须管：

```sh
python3 tools/install.py --user-dir "$HOME/Library/Rime"
```

<details>
<summary>Windows / Linux 安装命令</summary>

Windows 小狼毫（PowerShell）：

```powershell
py tools/install.py --user-dir "$env:APPDATA\Rime"
```

Linux fcitx5-rime：

```sh
python3 tools/install.py --user-dir "$HOME/.local/share/fcitx5/rime"
```

Linux ibus-rime：

```sh
python3 tools/install.py --user-dir "$HOME/.config/ibus/rime"
```

</details>

若曾修改用户目录，以前端菜单打开的“用户文件夹”为准。
安装器会保留已有方案列表、追加 `znabc`，覆盖前备份到 `.znabc-backups/`，个人词库不受更新影响。
可加 `--dry-run` 预览；复杂的 `default.custom.yaml` 格式会报错停止，此时加 `--no-enable` 并手动启用方案。

### 3. 重新部署

在 Rime 前端菜单执行 **重新部署**，再打开方案选单，选择 **智能 ABC · 复刻**。

先试一遍：输入 `nihao` → 空格打开选单 → 再按空格上屏 **你好**。

### 更新已有安装

在克隆的仓库目录中拉取更新，再运行安装器。例如 macOS：

```sh
git pull --ff-only
python3 tools/install.py --user-dir "$HOME/Library/Rime"
```

随后在前端执行 **重新部署**。只更新仓库不会自动更新 Rime 用户目录。
安装器保留个人词库 `znabc_user.userdb/`，候选顺序会继续受到已有学习记录影响。

<details>
<summary>没有 Python？手动复制安装</summary>

把仓库 `rime/` 内以下三个项目复制到 Rime 用户目录根部：

```text
znabc.schema.yaml
lua/
znabc_data/
```

`lua/` 与已有同名目录合并。模块放在 `lua/znabc/`，不需要修改已有 `rime.lua`。
在 `default.custom.yaml` 的现有 `patch:` 下添加以下两行；已有同名补丁键时，应直接在现有方案列表中追加 `schema: znabc`：

```yaml
patch:
  "schema_list/@next":
    schema: znabc
```

不要把第二个 `patch:` 粘贴到已有 `patch:` 的文件末尾。重新部署后切换方案。

</details>

## 输入体验

### 空格前编码，空格后选字

```text
ni32hao63  ── 空格 ──→  1. 你好  ── 空格 / 1 ──→  你好
    编码阶段                  选字阶段                  上屏
```

编码阶段的数字 `1..8` 参与字形过滤，候选打开后数字用于选字，两种用途互不抢占。
候选只匹配前一段时，选中后保留后面的编码，自动打开下一段选单，直接继续选择。
整词候选后会接上首音节的单字候选。例如 `wenti` 空格后先显示“问题、文体”，再显示 `wen` 的“问、文、闻、稳……”；选择其中一个单字后，直接显示 `ti` 的候选。无需先切换逐字模式，也无需再按空格打开选单。
下一段选单打开后，数字选择对应候选，空格直接确认当前高亮项；原版附加成分可能预选列表中的其他项。按 `Backspace`（macOS 的 Delete 回删键）撤销上一组已选字词，保留全部拼音和形码，并重新打开候选；可以连续按键逐组撤销。没有已选内容时，回删关闭选单并删除一位编码。需要直接修改剩余编码时，先按 `Esc` 关闭选单再编辑。没有匹配候选时保留编码，空格不会提交原始编码。

### 一次空格，连续选择

```text
wenti → 空格 → 选择“文” → 自动显示 ti 候选 → 选择“体” → 文体
```

**选完前段后，直接选下一段，不用再按一次空格。** 如果此时按空格，会确认下一段当前高亮的候选；`ti` 在词尾命中原版后加成分“体”，因此上例按空格也会得到“文体”。数字仍按列表中的编号选择，例如选“提”可得到“文提”。

自动续选适用于单字、仅匹配前段的词和 Tab 逐字模式。普通模式继续优先匹配剩余部分的词，Tab 模式继续只显示单字；每段候选从第一页开始。
最后一段选完才整串上屏，下一次新输入重新从编码阶段开始，不会直接打开候选。

### 原版前后附加成分

恢复原程序内置的 182 条记录：57 条仅前加、119 条仅后加、6 条前后均可。普通字词匹配优先；未匹配成较长词、需要分段选择时，开头的单字可命中前加成分，已有前段选字后的最后一段可命中一字或二字后加成分。

- `jiuni32hao63` 空格后，`jiu` 的候选仍按“就、九、酒、旧……”排列，自动高亮前加成分“旧”；按空格后继续选择“你好”。
- `wulixi` 空格选择“物理”，接着显示 `xi` 候选，自动高亮后加成分“系”；再按空格得到“物理系”。仍可按编号选择“西”等其他字。
- `wenti` 选择“文”后，自动高亮“体”；已匹配的整词仍保持原有学习和词频排序。

规则保留原始记录顺序、内部字码和读音，并接受全拼、简拼及音形过滤。“的”对应 `de`，原表后加成分“地”对应 `di`，不额外推导其他读音。`Tab` 逐字模式停用附加预选；普通单字独立输入、以词定字、纯笔形、GBK 和符号模式不触发。退格仍可撤销上一组选字，完成确认后的组合沿用现有学习设置。

此处只接入原版固定表和已确认的基础触发规则。现代构词扩充、递归组合及“的／地／得”语法判断暂存于 [backlog.md](backlog.md)。原版 Windows 完整交互与历史选择算法尚未全量复原。

### 想要的词不在候选里？逐字选，再记住它

`fuke` 的基础词候选是“复课、妇科”，后面附有 `fu` 的单字。直接选择“复”，随后在自动打开的 `ke` 候选中选择“刻”；也可以先按 `Tab` 隐藏词候选，专心逐字选择。
完成后上屏 **复刻**，并自动收录为新词；下次输入 `fuke` 就能整词选择。

### 用熟悉的词，取出需要的字

`shijie[` → **世**，`shijie]` → **界**。同样先按空格看候选，再确认上屏。
来源词显示在候选旁，基础词和自己学过的词都能使用。详细规则见[以词定字](#以词定字)。

### 一小段英文，一个 v 就够

`vlove` → 空格或回车 → **love**，`vLove` → 空格或回车 → **Love**。
保留大小写与数字，提交后继续中文输入，不需要切换中西文。
直接输入 `enter` 后按回车，没有 GBK 单字匹配时也会原样输出；使用 `venter` 后按空格或回车，则明确以临时英文输出 `enter`。

## 键位速查

| 按键 | 当前行为 |
| --- | --- |
| 字母 | 输入拼音或声母简拼 |
| `1..8` | 编码阶段输入形码，包括纯数字笔形输入；选单打开后选择对应候选 |
| `'` | 显式音节分隔 |
| 空格 | 首次打开选单；之后确认当前高亮候选，尚有剩余编码时自动打开下一段 |
| 选单中继续输入小写字母 | 完成旧串各段的当前高亮候选并上屏，再开始新编码；无候选或光标在编码中间时返回旧串编辑 |
| `1..9`（选字阶段） | 选择当前页对应候选；无对应候选时保持选单 |
| `Tab`（拼音选单打开时） | 切换整词优先／逐字选字，保留输入编码 |
| 词编码后加 `[` / `]` | 以词定字：取候选词的首字／末字；空格打开选单后选择 |
| `Ctrl+1..9` | 选单打开后也可选择当前页对应候选 |
| 上下方向键 | 移动候选高亮 |
| `PageUp` / `PageDown`、`-` / `=` | 翻页 |
| `Backspace` / macOS Delete | 选单中优先撤销上一组已选字词并重新选字；无已选内容时删除一位编码 |
| `Esc` | 选单打开时关闭选单、保留编码；编码阶段取消当前输入 |
| 单击 `Shift` | 切换中西文；有编码时先提交编码 |
| `v` + 英文字母或数字 → 空格或回车 | 直接上屏去掉首个 `v` 的内容，保留大小写，不切换中西文 |
| `i` / `I` + 数量词编码 → 空格或回车 | 直接上屏小写／大写中文数字及单位 |
| `v1` 至 `v9` → 空格或回车 | 打开符号选单，再按数字、空格或回车确认 |
| 回车（拼音或笔形编码时） | 有 GBK 匹配时打开单字选单，再次回车、空格或数字确认；无匹配时直接提交原码 |
| `[` / `]`（GBK 选单中） | 上／下一页；普通词选单仍按以词定字处理 |
| `Ctrl+Delete`（选单打开时） | 删除高亮用户词；基础词只清除个人使用记录，不删除基础词条 |

编码阶段不显示候选，数字不用于选字。第一次空格进入选字阶段，分段选中后保持选字阶段，数字不再追加形码。

例如 `zhongguo → 空格 → difang → 空格 → 空格` 会先提交“中国”，再提交“地方”。连续打字会沿用人工高亮和剩余段的附加成分预选；最后一词仍需显式确认。要继续修改旧编码，先按 `Esc` 关闭选单，再输入字母。GBK 选单和 `i` / `I` / `v` 特殊输入保持各自的编辑规则。

选单打开后输入分隔符会返回编码阶段继续输入；没有候选时，空格不会把原始编码上屏。
输入句点等中文标点仍可确认当前首选并输出标点。
临时英文示例：`vlove` → 空格直接上屏 `love`，无需第二次空格；`vLove` → 空格上屏 `Love`。
临时英文支持退格修改和 Esc 取消，提交后继续中文输入。单独 `v` → 空格上屏 `v`，`vv` → 空格也上屏 `v`。
临时英文中回车与空格一致：`venter` → 回车输出 `enter`，`vLove` → 回车输出 `Love`。
`v1` 至 `v9` 是符号选单的专用编码；`v12`、`v123`、`v0`、`v1abc` 仍直接输出去掉 `v` 的内容。

### 中文数字与数量词

小写 `i` 使用 `○一二三四五六七八九`，大写 `I` 使用 `零壹贰叁肆伍陆柒捌玖`。
输入后按一次空格或回车直接上屏；退格修改编码，Esc 取消。不进入数字选单，也不参与自动造词。
前缀是字母 `i`／大写 `I`，例如 `I1` 输出“壹”；字母 `l` 仍作为普通拼音输入。

| 编码 | 输出 | 编码 | 输出 |
| --- | --- | --- | --- |
| `i123` | 一二三 | `I123` | 壹贰叁 |
| `I20000` | 贰零零零零 | `I2w` | 贰万 |
| `i1b2s3` | 一百二十三 | `I1b2s3` | 壹佰贰拾叁 |
| `i2006n6y3sr` | 二○○六年六月三十日 | `iqk` | 千克 |
| `i1/2` | 一除二 | `i2*3` | 二乘三 |

遵循原版逐码替换：`i123` 不会自动补上“百、十”。`s/b/q` 对应十／百／千，大写 `I` 模式对应拾／佰／仟；单位字母不区分大小写。
其他编码：`g` 个、`w` 万、`z` 兆、`n` 年、`y` 月、`r` 日、`j` 斤、`d` 第、`$` 元、`k` 克、`m` 米、`f` 分、`l` 里、`t` 吨、`e` 亿、`o` 度、`h` 时、`p` 磅、`c` 厘、`u` 微、`a` 秒、`i` 毫、`x` 升，`+` 加、`-` 减、`*` 乘、`/` 除。
最长 20 个字符（包含前缀）；单独 `i`／`I` 确认为一／壹。原版不支持的小数点等编码保留在编辑区，不转换、不上屏，可退格修改。

### GB2312 符号与 GBK 单字

`v1` 至 `v9` 对应 GB2312 第 1 至 9 区，按原字节顺序列出各区已定义符号。先按空格或回车打开选单，再用数字、空格或回车选择，PageUp／PageDown 翻页。

普通空格查询沿用基础字词库和独立音形摘要。回车则打开原版扩展表的 GBK **单字**查询，支持拼音前缀加最多六位完整笔形码前缀，也支持纯笔形；不参与词频学习。
例如 `rong34`、`rong3414`、`r34144`、`ro34` 按回车均可查“鎔”，`pan335734` 可查“槃”，`cu4` 可查“麤”。
两种模式的数字后缀含义不同：普通空格使用原摘要，GBK 回车使用完整笔形前缀；不会把完整笔形直接替换为普通摘要。
GBK 选单内 `[`／`]` 翻页，数字、空格或再次回车确认；Esc 退出 GBK 选单并保留编码，再按空格恢复普通查询。回车查询没有匹配时直接提交原始编码，例如 `enter` → 回车输出 `enter`；即使普通空格选单已打开，也按这条规则处理。无候选时空格仍保留编码。

候选词只覆盖输入前半段时，选中后保留剩余编码并自动打开下一段选单；下一段仍优先显示匹配的词，再附首音节单字。本版不自动把多个短词拼成一个整句候选。

如果整词候选里没有需要的词，例如 `fuke` 的基础词只有“复课、妇科”，可以直接选后面的单字，或空格后按 `Tab` 改为仅显示逐字候选。
先在 `fu` 的候选中选择“复”（可翻页），接着在自动打开的 `ke` 候选中选择“刻”，整词上屏“复刻”。
逐字模式在本串编码的剩余部分继续生效，全部上屏或清空后恢复整词优先。
选单中再按 `Tab` 可恢复剩余编码的词与单字混合候选。该切换保留词候选的最长匹配规则、个人学习排序及单字字频顺序。

### 以词定字

在完整词编码末尾加 `[` 取首字，加 `]` 取末字。例如：

| 输入 | 预期 |
| --- | --- |
| `shijie[` → 空格 → 空格或 `1` | 从“世界”取“世” |
| `shijie]` → 空格 → 空格或 `1` | 从“世界”取“界” |
| `fuke]` → 空格 | 基础词“复课、妇科”分别提供“课、科”；选择对应数字上屏 |

候选旁显示来源词，顺序沿用词候选排序；结果字相同时只保留排序靠前的来源。
已学习的用户词同样参与，例如收录“复刻”后，`fuke]` 也能取“刻”。
形码后缀仍有效，例如 `ni32hao63]` 取“好”。
也可先打开普通词选单，再按 `[` / `]` 直接转换候选；再次按方括号替换原后缀，退格删除后缀后可重新空格选词。
以词定字时 `Tab` 不切换逐字模式。只有覆盖后缀前全部编码的词才参与，单音节或没有完整匹配词时无候选，空格不会提交原始编码。
取字操作不增加来源词使用次数；包含取字的一次输入不自动造词，也不更新个人使用记录。对取出的字按 `Ctrl+Delete` 不删除来源词。
临时英文 `v` 模式中的方括号保持原样，例如 `vlove]` → 空格输出 `love]`。

反馈时请提供：前端及系统、原始按键串、候选顺序、实际上屏结果、期望结果；出错时附前端日志中的 `znabc` / `Lua` 信息。

## 自动造词与分级用户词库

默认开启自动学习。一次输入完整编码，分几次选择字或短词，最后整串编码全部转换并上屏时，自动收录基础词库里没有的 2～9 字组合。
不同次已经上屏的独立输入不会合并；取消输入、直接提交原始编码、英文及纯笔形输入不用于造词。

例如首次输入 `ni32ni32`：空格 → `2` 选择“倪” → `2` 选择第二个“倪”，最终上屏“倪倪”。
再次输入 `ni32ni32`，空格后即可整词选择“倪倪”；全拼 `nini` 和简拼 `nn` 也能查询，字形后缀仍参与过滤。
基础词库已有其他同音词时，可用 `Tab` 逐字组合，例如上述“复刻”；完成后同样自动收录，下次 `fuke` 可以整词选择。
分段选择期间仍处于同一次编码转换，按数字只选择一段，下一段自动打开选单，整串完成后才上屏并学习。

| 级别 | 规则 |
| --- | --- |
| 基础词 | 原始词库保持只读，个人使用次数单独记录 |
| 临时新词 | 收录时后续使用次数为 0，候选注释显示 `〔新词 0/3〕`；每次完整提交后增加一次 |
| 常用用户词 | 临时词后续选用 3 次后晋升，注释显示 `〔常用〕`，不自动淘汰 |

临时词默认容量 2,000 条，满时优先淘汰使用次数少、较久未使用的词。每次收词和计数更新都会写入独立的 `znabc_user.userdb/`，重新部署和更新方案不覆盖该数据库。
保存实际选中的内部字码，保留多音字的读音，不将形码后缀当成读音编码。

词候选先按最长匹配词长选择；同长度依次考虑常用用户词、已有个人选择记录的基础词、临时新词、其他基础词。
同级按使用次数、最近使用时间排序，其后保留基础权重及原顺序；学习项与相同内部字码的基础项合并。
首音节单字附在这些词候选之后，保留原有字频顺序；选择单字只消耗对应音节及形码，剩余编码继续转换。以词定字与纯笔形输入不附加这组单字。
此分级排序是本版的产品规则，并不声称完全复刻原 ABC 的历史输出和合成权重。

在 Rime 方案选单中切换：

- **冻结学习**：继续查询用户词，但不自动新增或累计使用次数；主动删除仍可用。
- **基础词库**：停用用户词和个人排序，同时停止学习，恢复基础匹配与排序。
- **自动学习 / 用户词库**：恢复相应功能。默认每次加载本方案启用。

选中误收词后按 `Ctrl+Delete` 删除，同时保存禁止再次自动收录的标记。删除基础词候选仅清除其个人记录并保存同样标记，基础词仍可查询。
删除标记针对该读音下的内部字码序列；当前没有界面用于撤销标记或手动固定词条。
数据库使用 librime-lua 的 LevelDb 接口；接口不可用或打开失败时，输入法退回基础查询并记录日志。数据库写入失败也会记入前端日志。
暂未实现用户词跨设备同步、手动固定词及原版单字选择历史。

可在 `znabc.custom.yaml` 中调整以下配置，重新部署生效：

```yaml
patch:
  "znabc/learning/min_length": 2
  "znabc/learning/max_length": 9
  "znabc/learning/promotion_uses": 3
  "znabc/learning/temporary_capacity": 2000
```

已有该自定义文件时，将条目合并到现有 `patch` 中。临时容量在收录新词时执行淘汰；缩小配置不会立即清理整个已有词库。

## 数据与兼容范围

使用已有逆向结果直接生成：

- 75,705 条基础词记录，保留原始内部字码、权重和词库顺序。
- 7,231 条有读音的单字记录，包含多音字的独立读音码。
- 7,787 条正常基础笔形关系；不可输入的异常标记不进入运行数据。
- 拼音形码后缀使用专用摘要表，不以完整笔形码前两位替代。
- 单字频度从原 OVL 的频度区恢复，未覆盖的字按原函数回退值处理。
- 词候选先取最长有结果的词长，同词长按权重降序、同分保留词库顺序。
- 单字按权重降序，同分按内部字码升序；纯笔形按原表顺序。
- GBK 扩展表提供 21,008 个字符、27,927 条读音笔形记录，保留原索引顺序，多音记录按字去重；拼音与笔形索引不一致或格式异常的 7 个字节身份排除。
- 扩展表采用 GB18030 解码原字节，包含私用区映射；字符显示取决于当前字体覆盖。
- 数量词表直接从原程序导出；符号按 GB2312 第 1 至 9 区生成。

本版本接入基础词库、独立用户词库，以及上述扩展单字和特殊输入模式。原版历史选择算法及完整原界面交互尚未复原。
默认开启学习，个人记录会影响词候选排序；切换“基础词库”可恢复无学习时的原始候选顺序。
本仓库包含输入法源码及生成的基础词库，不包含原始程序、逆向分析工作区或个人用户词库。

## 字表核对台

本地 Web 工具用于核对缺失字、拼音、音形数字后缀和纯笔形码。只需 Python 3，无需安装前端依赖：

```sh
python3 tools/review_server.py
```

浏览器打开 <http://localhost:8765>。SQLite 数据库默认保存在 `.cache/character-review/review.sqlite3`，保存后关闭页面或重启服务仍可继续；备份时建议停止服务后复制数据库。

左侧可切换缺失常用字、其他语料缺字、原版恢复、已有字读音差异和基础字表，支持按汉字、拼音、形码或 Unicode 搜索。缺字范围默认只显示待核对项；自动恢复的记录可在“原版恢复”中查看。

新增字在原版拼音、笔形双索引中的全部记录一致，且完整笔形码的前 1～2 位唯一时，自动采用原版拼音与笔形码，并生成音形后缀。例如“槃”：`pan / 335734`，后缀为 `33`。多个前缀时保留已恢复的原码，后缀留空并列入待核对；单索引、索引不一致或解析异常均不自动采用。只有外部语料提供的信息仍需人工核实。

已有字保留原版独立的音形摘要，不以其他笔形前缀覆盖。例如“比”的摘要为 `16`，即使另有 `61` 开头的笔形码也不改写。新增字编辑完整笔形码时，前缀唯一则自动生成后缀，多个前缀则提示选择；形码可暂缺。人工核对标记与原版自动恢复分开记录。

记录可保存为草稿、已确认、待考证或暂不收录，保留修改历史，并支持按状态导出 JSON / TSV。导出包含原版恢复和人工保存的记录，标注 `source` 与 `suffix_source`；原版恢复的修改版本为 0，不伪造人工修改历史。人工保存优先于自动值，重启或重新载入来源不会覆盖人工决定。`Ctrl/Cmd+S` 保存草稿，`Ctrl/Cmd+Enter` 确认并进入下一字。核对台不会直接修改 Rime 字库。

本工作区默认读取上级 `analysis/lexicon-comparison/` 的缺字对比结果、`analysis/export/extension-table.csv` 和 `/data/lexicon/EncodeTable/stroke.json`。这些外部来源不随本仓库分发；缺失时仍可查看基础字表。其他工作区可通过 `--comparison-dir`、`--export-dir`、`--lexicon-dir` 指定来源，通过 `--database` 指定独立数据库。

后端回归测试：

```sh
python3 -m unittest discover -s tests -p 'test_review_server.py' -v
```

## 开发

目录结构：

```text
rime/znabc.schema.yaml       Rime 方案与键位
rime/lua/znabc_processor.lua 编码与选字状态、空格和数字按键
rime/lua/znabc_translator.lua 候选区间、预编辑与 Rime 适配
rime/lua/znabc/parser.lua    移植的连续输入解析
rime/lua/znabc/engine.lua    查询、过滤和排序
rime/lua/znabc/dictionary.lua 数据加载与分桶缓存
rime/lua/znabc/user_dictionary.lua 用户词持久化、晋升、淘汰和删除标记
rime/lua/znabc/learning.lua   单次编码的提交验证与收词
tools/build_data.py         从已有样本生成数据
tools/install.py            复制安装及配置追加、备份
tools/package.py            构建完整安装 ZIP
tests/                      Lua、原 x86 对照和真实 Rime API 测试
```

仓库已包含运行所需的基础词库。克隆后可以直接安装：

```sh
python3 tools/install.py --user-dir "$HOME/Library/Rime"
```

在鼠须管菜单执行“重新部署”后选择“智能 ABC · 复刻”。其他平台的用户目录见[快速安装](#快速安装)。

构建完整安装包：

```sh
python3 tools/package.py
```

输出为 `dist/rime-znabc-0.3.1.zip` 及 SHA-256 校验文件。安装包解压后使用根目录的 `install.py`，例如 `python3 install.py --user-dir "$HOME/Library/Rime"`。

仅在重新提取基础词库时运行 `python3 tools/build_data.py`；该工具会引用外部工作区的 `analysis/znabc_formats.py` 和已解压的样本，这些文件不在本仓库中。日常开发、安装、打包和 Lua 内核测试直接使用仓库中的词库；输入法运行不依赖 Python。
完整重建还会导出数量词、符号和 GBK 扩展数据；仅重建这部分可执行 `python3 tools/build_special_data.py`，同样需要原始样本。它们随安装包提供，运行时无需访问原版文件。
词库按前两字首字母分成 516 个桶，按需读取并缓存，避免每次按键全表扫描。

本工作区的依赖只解压在 `.cache/runtime/`，没有改动系统 Rime 安装。
